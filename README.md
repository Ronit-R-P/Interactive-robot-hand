An interactive web-based 3D visualization of my robotic/prosthetic hand model.

The project allows you to:

Inspect and rotate the 3D hand model.
Explore the hand geometry and individual components.
Interactively control the hand's actuators using sliders.
View joint movements in real time directly in the browser.
Explore the underlying meshes and model structure.


Built with MuJoCo/WebAssembly and web-based 3D visualization, and deployed using GitHub Pages.
